# Smart Asset Intelligence System - Duplicate Detection

## Overview

The Duplicate Detection Engine identifies exact duplicates, near-duplicates, and similar compositions across an asset library. It uses perceptual hashing, visual similarity analysis, and metadata comparison to detect redundancy. Each detection includes a match type classification and similarity score.

## Match Types

| Match Type | Score Range | Description |
|------------|-------------|-------------|
| `exact` | 95-100 | Byte-identical or perceptually identical |
| `near_duplicate` | 80-94 | Very similar with minor differences (compression, crop, resize) |
| `similar_composition` | 60-79 | Similar layout, colors, or structure |
| `visual_variant` | 40-59 | Similar visual elements but different arrangement |
| `low_similarity` | 0-39 | Minimal similarity, unlikely to be duplicate |

---

## Detection Methods

### 1. Perceptual Hashing

Compares image fingerprints that are resilient to minor modifications:

```
Original Image -> Generate pHash -> hash_1
Comparison     -> Generate pHash -> hash_2
Distance(hash_1, hash_2) -> Similarity Score
```

| Hamming Distance | Similarity | Match Type |
|-----------------|------------|------------|
| 0-2 | 95-100% | exact |
| 3-6 | 80-94% | near_duplicate |
| 7-10 | 60-79% | similar_composition |

### 2. Visual Similarity Analysis

AI-powered comparison of visual features:

- Color histogram comparison
- Edge detection pattern matching
- Texture analysis
- Composition layout comparison

### 3. Metadata Comparison

Structural metadata matching:

| Field | Match Weight | Description |
|-------|-------------|-------------|
| Dimensions | 20% | Same width and height |
| Format | 10% | Same file format |
| File Size | 15% | Similar file size (within 10%) |
| Colors | 25% | Similar dominant colors |
| Duration | 20% | Same duration (video/audio) |
| AI Model | 10% | Generated by same model |

## Detection Flow

```
New/Updated Asset
    |
    v
Hash Generation -> Compute perceptual hash
    |
    v
Candidate Search -> Find assets with similar hashes
    |
    v
Visual Comparison -> Detailed similarity analysis
    |
    v
Metadata Comparison -> Structural matching
    |
    v
Score Aggregation -> Combine scores with weights
    |
    v
Match Classification -> Assign match type
    |
    v
Persist Duplicates -> asset_duplicate
```

---

## Resolution Workflow

```
detected -> resolved (confirmed duplicate, action taken)
detected -> ignored (false positive, not a duplicate)
ignored -> detected (re-evaluate)
resolved -> detected (reopen)
```

### Resolution Actions

| Status | Action | Description |
|--------|--------|-------------|
| `detected` | Review | Pending user review |
| `resolved` | Merge/Delete/Keep | User decided on action |
| `ignored` | Dismiss | Marked as false positive |

## Query Examples

### Find all exact duplicates

```sql
SELECT ad.*, am.title, am.asset_type
FROM asset_duplicate ad
JOIN asset_metadata am ON ad.duplicate_asset_id = am.asset_id
WHERE ad.user_id = $1 AND ad.match_type = 'exact'
ORDER BY ad.similarity_score DESC;
```

### Find unresolved duplicates

```sql
SELECT ad.*, am.title
FROM asset_duplicate ad
JOIN asset_metadata am ON ad.duplicate_asset_id = am.asset_id
WHERE ad.user_id = $1 AND ad.status = 'detected'
ORDER BY ad.similarity_score DESC;
```

### Get duplicate statistics

```sql
SELECT
  match_type,
  status,
  COUNT(*) as count,
  AVG(similarity_score) as avg_similarity
FROM asset_duplicate
WHERE user_id = $1
GROUP BY match_type, status;
```
