# AUTO-01: Reports

## Overview

The Report Engine generates analytics and performance reports for automation rule executions. It aggregates execution data to provide insights into success rates, credit usage, and overall automation performance.

## Report Types

| Report Type | Description | Typical Period |
|---|---|---|
| `execution_summary` | Overall execution statistics | Any |
| `daily` | Daily execution report | Day |
| `weekly` | Weekly execution report | Week |
| `monthly` | Monthly execution report | Month |
| `credit_analysis` | Credit usage analysis | Any |
| `performance` | Performance metrics | Any |

## Report Structure

```typescript
{
  id: string;                    // Prefixed ID: "arep_xxx"
  userId: string;                // Owner
  reportType: string;            // Report type identifier
  period?: string;               // Time period (e.g., "2024-01", "2024-W03")
  data: ReportData;             // Detailed report data
  summary: ReportSummary;       // Aggregated summary
  generatedAt: Date;            // When the report was generated
}
```

### Report Data

```typescript
interface ReportData {
  totalExecutions: number;        // Total execution count
  completedExecutions: number;    // Successful executions
  failedExecutions: number;       // Failed executions
  totalCreditsUsed: number;       // Total credits consumed
  totalRules: number;             // Number of automation rules
  totalEvents: number;            // Number of events processed
  period?: string;                // Time period filter
}
```

### Report Summary

```typescript
interface ReportSummary {
  successRate: number;                    // Percentage (0-100)
  failureRate: number;                    // Percentage (0-100)
  averageCreditsPerExecution: number;     // Mean credits per execution
}
```

## Data Collection

Reports are generated by aggregating data from three sources:

### 1. Execution Data (`automation_execution`)

```sql
SELECT
  COUNT(*) as totalExecutions,
  SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) as completedExecutions,
  SUM(CASE WHEN status = 'failed' THEN 1 ELSE 0 END) as failedExecutions,
  SUM(credits_used) as totalCreditsUsed
FROM automation_execution
WHERE user_id = ?
```

### 2. Rule Data (`automation_rule`)

```sql
SELECT COUNT(*) as totalRules
FROM automation_rule
WHERE user_id = ?
```

### 3. Event Data (`automation_event`)

```sql
SELECT COUNT(*) as totalEvents
FROM automation_event
WHERE user_id = ?
```

## Success/Failure Rates

The Report Engine calculates:

- **Success Rate**: `(completedExecutions / totalExecutions) * 100`
- **Failure Rate**: `(failedExecutions / totalExecutions) * 100`
- **Average Credits Per Execution**: `totalCreditsUsed / totalExecutions`

### Rate Calculation

```typescript
const total = Number(totalExecutions?.count ?? 0);
const completed = Number(completedExecutions?.count ?? 0);
const failed = Number(failedExecutions?.count ?? 0);

return {
```

## Credit Analysis

Credit analysis tracks:

- **Total Credits Used**: Sum of `creditsUsed` across all executions
- **Average Credits Per Execution**: Mean credit consumption
- **Credits by Rule**: Credit usage breakdown by automation rule
- **Credits by Action Type**: Credit usage breakdown by action type

## Report Generation

### API Method

```typescript
async generateReport(userId: string, reportType: string, period?: string)
```

### Generation Flow

1. Collect execution, rule, and event data
2. Calculate summary statistics
3. Store report in `automation_report` table
4. Return generated report

### API Endpoint

```
POST /api/automation/reports
```

Request:
```json
{
  "reportType": "execution_summary",
  "period": "2024-01"
}
```

Response:
```json
{
  "success": true,
  "data": {
    "id": "arep_xxx",
    "reportType": "execution_summary",
    "period": "2024-01",
    "data": {
      "totalExecutions": 150,
      "completedExecutions": 140,
      "failedExecutions": 10,
      "totalCreditsUsed": 7500,
      "totalRules": 12,
      "totalEvents": 200
    },
    "summary": {
      "successRate": 93,
      "failureRate": 7,
      "averageCreditsPerExecution": 50
    }
  }
}
```

## CRUD Operations

| Method | Description |
|---|---|
| `generateReport(userId, reportType, period?)` | Generate a new report |
| `listReports(userId, filters?)` | List reports with pagination |
| `getReport(id)` | Get a single report |
| `deleteReport(id)` | Delete a report |

## Report Listing

Reports can be filtered by type and paginated:

```
GET /api/automation/reports?reportType=daily&page=1&limit=20
```

Response:
```json
{
  "success": true,
  "data": [...],
  "pagination": {
    "total": 30,
    "page": 1,
    "limit": 20,
    "totalPages": 2
  }
}
```
